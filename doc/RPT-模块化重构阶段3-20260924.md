## 七、技术教训

1. **大文件 Edit 工具不可靠**：对 >100KB 文件常报 "File has not been read yet"，一律用 Python 补丁脚本。
2. **正则 DOTALL 在大文件上回溯极慢**：改用按行号范围删除（assert 关键行号 + del lines[start:end]）。
3. **补丁删除函数块可能留下空 def 行**：需 py_compile 验证后修复。
4. **scp -r 复制已存在目录会嵌套**：需逐个文件 scp。
5. **PowerShell 内联 python -c 引号必冲突**：禁止；跑脚本用 `python script *> TEMP\out.txt; Get-Content out.txt`。
6. **E:\NAS 是 SMB 网络盘**：命令常超 15s 被移后台，用 TaskOutput block 等。
7. **路由模块接收 handler 作为参数**：因为 _json/_send_png/_handle_tool 是 TVPilotHandler 的方法，不能完全脱离 handler。这是绞杀者模式的合理折中。
