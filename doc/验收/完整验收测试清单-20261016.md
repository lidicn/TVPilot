## 四、UI Dump 验收

### 4.1 UI 元素读取

**提示词**：
```
测试 UI dump：
1. 回桌面
2. 调用 tv_ui_dump，看看能读到多少个元素
3. 看看每个元素有没有 element_id、text、bounds、type
4. 看看元素是不是按可点击优先排序的
```

**预期结果**：
- ✅ 能读到桌面图标元素
- ✅ 每个元素有稳定的 element_id
- ✅ 元素有类型（button/input/text）

---

### 4.2 按元素索引点击

**提示词**：
```
测试按索引点击：
1. 先 tv_ui_dump，拿到元素列表
2. 选一个可点击的元素（index=0）
3. 调用 tv_tap_index(0) 点击它
4. 看看是不是点中了
```

**预期结果**：
- ✅ 能按索引点击
- ✅ 不需要自己算坐标
