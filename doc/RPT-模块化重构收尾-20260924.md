## 一、完成项

### 1.1 config.py — 集中配置

**文件**：`tvpilot/config.py`（新建）

将主文件中分散的 40+ 配置常量集中到 config.py：
- 基础配置：PORT, TVPILOT_VERSION, BASE_DIR, STATIC_DIR, CH_FILE, DATA_DIR
- ADB：ADB_HOST, ADB
- 应用包名：MYTV_PKG, MYTV_ACT, IPTV_PKG, IPTV_ACT, TRIM_PKG, TRIM_ACT, ARC_BASE
- tvremoteime：TVREMOTEIME_PKG, TVREMOTEIME_SVC, TVREMOTEIME_ACTION
- MQTT：MQTT_HOST, MQTT_PORT, MQTT_USER, MQTT_PASS, MQTT_IN, MQTT_OUT 等
- doubao2api：DOUBAO_API_URL, DOUBAO_API_KEY, DOUBAO_MODEL
- go2rtc（归档）：GO2RTC_BASE, GO2RTC_AUTH_USER, GO2RTC_AUTH_PASS, GW_ACTIVE
- RTSP 刷新（归档）：ADMIN_TOKEN, DEVICE_TOKEN, REFRESH_OPEN, REFRESH_MIN_INTERVAL, DOCKER_SOCK, WAKE_LOCAL
- 锁：_FG_LOCK, _DEDUP_LOCK
- 状态：_refresh_rtsp_state

主文件从 config.py import 所有配置，删除了 68 行重复定义。

### 1.2 Dockerfile 更新

**文件**：`Dockerfile`（修改）

添加：
```dockerfile
# 模块化包（绞杀者模式重构）
COPY tvpilot/ /app/tvpilot/
```

解决了"容器内 /app/tvpilot/ 包是 docker cp 进去的，不在 Dockerfile COPY 清单中，下次重建镜像会丢失"的问题。

### 1.3 路由表重构

**文件**：`tvpilot_server.py`（修改）

将 do_GET/do_POST 的 if-elif 链改为列表遍历：

```python
GET_HANDLERS = [
    handle_remote,
    handle_iptv_routes,
    handle_media_get,
    handle_users_get_all,
    handle_a11y_get,
    handle_legacy_get,
    handle_state_routes,
    handle_channels,
    handle_epg_api,
]

POST_HANDLERS = [
    handle_media_post,
    handle_users_post,
    handle_control_post,
    handle_a11y_post,
    handle_ask_post,
]

def do_GET(self):
    ...
    for handler_fn in GET_HANDLERS:
        if handler_fn(self, path, q):
            return

def do_POST(self):
    ...
    for handler_fn in POST_HANDLERS:
        if handler_fn(self, path, body):
            return
```

消除了 9 个 GET + 5 个 POST 的重复 if-elif 代码。
