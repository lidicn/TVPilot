## 关键设计决策（阶段2）
1. **health.py 延迟 import _mqtt_pub**：避免 health→mqtt→health 循环依赖，`_get_mqtt_state()` 优先从主文件取实时引用
2. **mqtt.py 延迟 import 主文件函数**：`trim_search`/`handle_face_recognition`/`handle_wake_command` 在函数内 import，避免模块加载期循环
3. **vision.py 自包含 DOUBAO 常量**：DOUBAO_API_URL/KEY/MODEL 从环境变量读，不依赖主文件
4. **logos.py CCTV 配色优化**：CCTV-5 体育用蓝色，其他用经典红；卫视 30 个频道代表色映射
5. **iptv.py 启动时加载频道ID映射**：`_load_channel_id_map()` 在模块加载时执行，与原行为一致

## 风险与注意
- 容器内 `/app/tvpilot/` 包是 docker cp 进去的，不在 Dockerfile COPY 清单中——下次重建镜像会丢失，需更新 Dockerfile
- 主文件中仍有 `ADB_HOST`/`MYTV_PKG`/`MQTT_*`/`TRIM_*` 等重复常量（模块中已自包含定义，主文件保留冗余副本）——后续 config.py 统一消除
- TVPilotHandler 路由分发是最大耦合点，迁移需逐路由分析依赖，建议拆分为多个子模块（如 routes_zap.py, routes_query.py, routes_admin.py）
