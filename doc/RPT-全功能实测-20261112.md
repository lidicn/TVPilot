## 2. 范围 A ②：换台实际走哪条 + 80/60 差集复算

**换台主链路（现读 + 实测双证）**：`tv_zap` → `tvpilot/tools.py:515 tool_zap` → `:548 channel_no_of(name)` 取台号 → `:494 zap_via_adb_digits` → `adb shell "input keyevent KEYCODE_2 && … && KEYCODE_ENTER"`；前台目标 `com.tvcam.mytv`（`IPTV_PKG` 常量在 `state.py:19` 是电信 IPTV，`mytv` 是播放器）。**与 go2rtc / RTSP `setp` 无关**——`setp` 只在 `doc/archive/电信IPTV_RTSP地址抓取流程.md` 的历史文档里出现，仓内活代码 0 处。

**80 键 vs 可换 60（numbers 是嵌套对象 `channel_numbers.json.numbers`，别按平铺算）**：

| 项 | 读数 |

### 5.4 异常与恢复（必读）

`tv_go_home` 把前台从电信 IPTV 切到小米桌面 `com.mitv.tvhome` 后，自动恢复链断：`tv_launch_app` 对**真实存在**的 IPTV 包报「包未安装」，`tv_zap` 全部报「mytv 未能切到前台」，`/api/current` 从「中央一台/21」漂到「深圳少儿/4」，第一次 adb 数字键恢复后读数仍乱跳（21→4→2→1）。

**处置（已即时报 AF-PM）**：绕过坏掉的 `tv_*`，用 adb 原生恢复
