## 5. 目录与命名约定

1. **`doc/` = 正式文档；`docs/` = 已就地降级的归档素材目录**。新文档一律进 `doc/`，`docs/` 只增不改、不作为规范引用。
2. **命名**：报告用 `RPT-<主题>-<YYYYMMDD>.md`；契约/接口用 `<名称>_v<版本>.md`；回执/日志按 `DEV日志/` 归档。
3. **状态标注**：✅ **已执行**（见 §7）。给 55 份 `.md` 头部插入统一状态标，分「已取代／过期」「部分落后」「现行基线」「历史记录」四类；各文件原有 BOM／CRLF／NUL 原样保留。
4. **现行报告增量更新**：沿用现有「追加 §N、不改旧节」写法，引用按章号。
5. **暂不搬目录**：`RPT-全功能实测` §1 逐条列了 `doc/xxx.md:行` 形式的文件:行证据，物理移动会打断这些引用；若要做 `01-现行/`、`02-契约/`、`03-报告/`、`04-历史/` 分层，需连同引用一起改，单独开单。本轮按此执行，**未移动任何文件**。
