## Bug 修复
1. `get_audio_info()` 中调用了未定义的 `log()` 函数 → 改为 `print()`
2. `_FG_LOCK` 在主文件中未定义（ensure_mytv_foreground 调用时会 NameError）→ 在 tools.py 中补定义 `threading.Lock()`

## 主文件变更
- 删除：11 个模块共约 1400 行代码（函数+常量+字典）
- 新增：11 个 `from tvpilot.* import ...` 块（约 90 行）
- 净减：约 1341 行（3734 → 2393）

## 关键设计决策
1. **自包含原则**：每个模块自己从环境变量读配置，不依赖主文件 config，避免循环依赖
2. **绞杀者模式**：主文件仍保留路由分发和业务编排，仅底层函数从包 import
3. **延迟 import**：state.py 的 tool_play_state 中对 proxy_mytv 使用函数内延迟 import
4. **legacy 归档不删**：go2rtc/mytv代理/warmup 完整保留在 legacy.py，用户明确要求"万一哪天要用"

## 部署踩坑记录
- scp -r 复制已存在目录会嵌套（`tvpilot/tvpilot/`），需逐个文件 scp
- 大文件 Edit 工具常报 "File has not been read yet"，一律用 Python 补丁脚本
- 正则 DOTALL 在 150KB 文件上回溯极慢会卡死，改用按行号删除
- 补丁删除函数块时可能留下空 def 行（IndentationError），需 py_compile 验证后修复

## 风险与注意
- 容器内 `/app/tvpilot/` 包是 docker cp 进去的，不在 Dockerfile COPY 清单中——下次重建镜像会丢失，需更新 Dockerfile
- 主文件中仍有 `ADB_HOST`/`CH_FILE` 等重复常量——后续迁移 config.py 时统一
- RTSP 刷新逻辑（`_do_refresh_rtsp` 等）仍在主文件，用户说不需要解决但也没删——后续可归档到 legacy.py
