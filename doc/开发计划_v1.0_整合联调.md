## 二、T1：mytv HTTP API 换台接口（详细）

### 背景
管家 ReAct 联调时，"换到湖南卫视"场景未完全通过。可能原因：
- mytv HTTP API 换台接口不存在/参数不对
- ADB zap_channel 工具可用，但 mytv 专属 API 有问题
- 频道名称映射问题（"湖南卫视"→频道号/源 ID）

### 排查步骤
1. 确认 mytv 换台 API 端点：`POST /api/mytv/switch_channel` 或类似
2. 测试 API 直接调用：`curl -X POST http://192.168.2.238:8080/api/mytv/switch_channel -d '{"channel":"湖南卫视"}'`
3. 检查 TV 端实际是否换台成功
4. 如果 API 有问题，修复或回退到 ADB zap_channel
5. 更新 API 文档

### 验收标准
- 管家调用换台工具 → TV 实际换到指定频道
- current/foreground 验证返回正确频道信息
- 错误频道名返回明确错误码

## 五、T8：适配统一指令中心（详细）

### 背景
管家统一指令中心 API 已就绪，TP 需要实现轮询拉取和状态上报。

### 实现内容
1. 后台线程每 30 秒轮询：`GET http://192.168.2.200:8095/api/commands/pull/TP`
2. 拉取到 pending 指令后：`POST /api/commands/{id}/accept`
3. 执行指令（根据指令内容调用对应工具）
4. 完成后：`POST /api/commands/{id}/complete`（body: {result: "完成说明"}）
5. 失败时：`POST /api/commands/{id}/fail`（body: {error: "错误信息"}）
6. 认证：请求头 `Authorization: Bearer admin`

### 验收标准
- PM 在看板创建 target=TP 的指令
- TP 在 30 秒内拉取并 accept
- TP 执行完成后 complete，看板状态更新
- 轮询不影响 TVPilot 正常功能（异步后台线程）
