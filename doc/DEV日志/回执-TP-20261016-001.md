## 二、代码改动详情

### BUG-2 唯一代码改动（tools.py tool_force_stop 函数）

```python
# 改动前（残留静默 fallback）:
except Exception:
    pass  # 检查失败不阻断          # ← 包检查失败时跳过校验，直接 force-stop
...
except Exception:
    stopped = True                # ← pidof 失败时默认"已停止"，谎报成功

# 改动后:
except Exception as e:
    return None, ERR_TV_UNREACHABLE, f'无法检查包是否安装（ADB不可达）: {e}'
...
except Exception:
    result = {'package': package, 'stopped': None,
              'warning': 'force-stop已下发，但pidof验证失败（ADB不可达），无法确认是否已停止'}
```
