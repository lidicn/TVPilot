## 一、原计划 vs 实际

### 原计划（P1）
在电视上装 Agent APK，用无障碍服务直接读 UI 树。

### 实际情况
调研后发现：
1. 大多数开源项目都是 ADB 方式（Mobile MCP、agent-droid-bridge）
2. 现成的 APK 都是完整 agent（TouchPilot、zerotap），不是 HTTP server
3. 需要自己编译的 APK（AndroidAgentBridge），工作量大

### 实际做的
改变思路，把 ADB 方式优化到极致：
1. **持久化 shell 会话**——避免每次启动新 adb 进程
2. **批量命令**（P0 已做）——减少网络往返
3. **剪贴板输入**（P0 已做）——解决中文问题

## 二、核心改进：持久化 Shell

### 原来的问题
每次执行命令都要：
1. 启动新的 adb 进程
2. 建立新的 TCP 连接
3. 执行命令
4. 关闭进程

开销大，速度慢。

### 现在的方案
1. 启动一个 `adb shell` 进程，保持 stdin/stdout 管道
2. 后续命令都写到这个进程的 stdin
3. 用特殊标记 `__TVPILOT_CMD_DONE__` 分隔命令输出
4. 失败自动重启 shell

### 效果
| 指标 | 原来 | 现在 | 提升 |
|------|------|------|------|
| 每次 keyevent | ~2s | ~1s | 快 1 倍 |
| 连续 5 次操作 | ~10s | ~5s | 快 1 倍 |
