# TVPilot v0.9.0 部署回执

> 部署时间：2026-10-16
> 版本：0.9.0（从 0.8.1 升级）
> 部署方式：docker compose up -d --build（完整重建，非热修）

---

## 一、本次改动清单

### 新功能（v1.1 补全）

| 功能 | 工具名 | 说明 |
|------|--------|------|
| 高亮截图 | tv_screenshot(highlight=true) | 在截图上用红圈+数字标出可交互元素 |
| XPath 定位 | tv_tap_xpath | 按 XPath 表达式点击元素 |
| 长按 | tv_long_press | 在指定坐标长按（菜单/多选场景） |
| 滚动 | tv_scroll | 按方向滚动列表（up/down/left/right） |
| 取元素详情 | tv_get_element | 获取指定索引元素的完整信息 |

### Bug 修复

| Bug | 修复内容 |
|-----|---------|
| BUG-2 tv_force_stop 谎报成功 | 包检查失败时返回错误，pidof 失败时不默认 stopped=True |

### 工程改动

| 项 | 改动 |
|----|------|
| 版本号 | 0.8.1 → 0.9.0 |
| docker.sock 挂载 | 已移除（compose + Dockerfile 都清理） |
| Dockerfile | 去掉 docker 包依赖 |
| MCP 工具上限 | MAX_TOOLS 21 → 30（原上限不够） |
