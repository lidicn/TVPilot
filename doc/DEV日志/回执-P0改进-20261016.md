## 一、改进内容

### P0.1 批量命令工具（tv_batch）

**新增工具**：tv_batch

**功能**：一次调用执行多个操作，减少网络往返，速度翻倍。

**支持的操作**：
| 操作 | 参数 | 说明 |
|------|------|------|
| tap | x, y | 点击坐标 |
| click_text | text, exact | 按文字点击 |
| input_text | text | 输入文字 |
| keyevent | key | 按键 |
| wait | seconds | 等待 |
| swipe | x1, y1, x2, y2 | 滑动 |
| launch_app | package, activity | 启动 App |

**示例**：
```json
{
  "actions": [
    {"action": "click_text", "text": "搜索"},
    {"action": "wait", "seconds": 1},
    {"action": "input_text", "text": "全资进组"},
    {"action": "keyevent", "key": "KEYCODE_ENTER"}
  ]
}
```

**原来 vs 现在**：
- 原来：4 次 MCP 调用，4 次网络往返
- 现在：1 次 MCP 调用，1 次网络往返

---

### P0.2 改进中文输入（剪贴板 + 重试）

**原来**：只用 tvremoteime 广播，经常不生效。

**现在**：
1. 优先用**剪贴板粘贴**方式
2. 失败则降级到 tvremoteime 广播
3. tvremoteime 失败自动**重试 2 次**
4. 每次重试增加等待时间（1s → 1.5s → 2s）

**返回字段**：
- method: 用的什么方式（clipboard_paste / tvremoteime_broadcast / ascii_input）
- verified: 是否验证成功
- attempts: 尝试了几次

---

### P0.3 优化 UI dump

**原来**：返回所有有文字或可点击的元素，token 消耗大。

**现在**：
1. **过滤不可见元素**：visible-to-user=false 的直接扔掉
2. **过滤太小元素**：宽或高 < 5px 的扔掉
3. **加稳定 element_id**：用 text + bounds 哈希生成，同一元素多次 dump ID 不变
4. **加元素类型推断**：button / input / text
5. **加 content-desc**：有些图标没有文字，只有描述

**返回字段**（每个元素）：
- index: 索引
- element_id: 稳定 ID（8 位哈希）
- text: 文字
- desc: 内容描述（图标用）
- bounds: [x1, y1, x2, y2]
- center: [x, y] 中心点
- clickable: 是否可点击
- focusable: 是否可聚焦
- editable: 是否可输入
- type: button / input / text
- class: 类名
- resource_id: 资源 ID
- xpath: XPath 路径
