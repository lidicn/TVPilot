# TVPilot 跨项目对接清单

> 日期：2026-09-22
> TVPilot 版本：0.8.1（已部署，health 全绿）
> 用途：TVPilot 自己能干的已全部干完，以下是需要其他项目/人员配合的事项。

---

## 1. 给豆包管家（doubao-butler）

### 1.1 API 调用需带 token（即将实施）

TVPilot 目前除 `/api/iptv/refresh` 外所有路由无鉴权。TVPilot 即将加全局 token 中间件，管家调用所有 `/api/*` 时需在 Header 带：

```
Authorization: Bearer <TVPILOT_ADMIN_TOKEN>
```

- **当前 token 值**：由 TVPILOT_ADMIN_TOKEN 环境变量注入（compose 里已配，32 字符 hex）
- **管家需要做的**：调用 TVPilot 工具时统一加 `Authorization: Bearer ...` 头
- **不需要改的**：PWA 遥控器页面（`/remote`）和静态资源不走 token
- **对接时机**：TVPilot 改完后通知管家，管家改完调用代码联调

### 1.2 端到端场景联调

以下 5 个场景需要管家侧写 ReAct 循环调 TVPilot 工具：

| 场景 | 管家需要做什么 | TVPilot 已就绪的工具 |
|---|---|---|
| 语音换台 | 识别"换到湖南卫视"→ 调 /api/zap | /api/zap, /api/channels, /api/current |
| 搜索播放 | 识别"搜流浪地球"→ 调组合动作 | /api/combo/trim_search_play {keyword} |
| 调音量/切信号源 | 识别"声音大一点"→ 调按键 | /api/keyevent |
| 多 App 切换 | 识别"打开飞牛TV"→ 启动 App | /api/launch_app |
| 回桌面 | 识别"回桌面"→ 组合动作 | /api/combo/go_home |

- **TVPilot 侧状态**：所有工具接口已就绪
- **管家需要做的**：在工具列表里注册 TVPilot 的 12 个 API，写 ReAct 循环
- **联调前置条件**：电视开机（192.168.2.238），mytv 在跑

### 1.3 request_id 全链路

TVPilot 的 `/api/history?request_id=xxx` 已支持按 request_id 查询操作存档。管家发起工具调用时在 POST body 里带 `request_id`，TVPilot 会记录并存档，管家可事后查询这次调用的完整执行轨迹。

## 2. 给出资人（用户本人）

### 2.1 TV-104 人脸端点 IP 白名单

人脸底库备份/恢复接口（`/api/face/backup`、`/api/face/restore`）目前无鉴权。TVPilot 计划加双轨门：token + IP 白名单。

- **需要你做的**：在路由器上给电视（192.168.2.238）做 DHCP 静态保留，然后把这个 IP 告诉 PM，PM 回填到 compose 的 `TVPILOT_FACE_ALLOW_IP`
- **为什么需要**：人脸备份接口允许局域网内任意主机读取/覆写人脸底库，IP 白名单是兜底——即使 token 泄露，不在白名单的 IP 也访问不了
- **当前状态**：阻塞中，TVPilot 侧代码已准备好，就等 IP 回填

### 2.2 电视端无障碍权限授权

v0.4 无障碍服务 APK 写好后，需要在电视上：
1. 设置 → 无障碍 → 开启 Arcface 的无障碍服务权限
2. adb install 安装 APK
- **需要你做的**：APK 写好后你在场操作电视授权（TVPilot 无法远程授权无障碍）

## 3. 给 go2rtc 维护者

### 3.1 配置热重载

TVPilot 已拔掉 docker.sock（不再能 docker restart go2rtc）。当前 TVPilot 刷新 RTSP 流后只写 yaml 文件到 go2rtc 配置目录，但 go2rtc 不会自动重载。

- **现状**：TVPilot 写 `/app/data/go2rtc_refreshed.yaml`，但 go2rtc 不读它
- **需要 go2rtc 做的**：支持 SIGHUP 热重载，或支持 API 触发重载，或轮询配置文件 mtime
- **临时方案**：需要人手动 `docker restart go2rtc`

## 4. 给 memory-agent

### 4.1 操作模板存储/检索

v1.0 规划：TVPilot 成功操作序列自动存到 memory-agent，下次相似任务先检索模板。

- **TVPilot 侧状态**：ops.jsonl 已记录所有操作（ts, tool, params, ok, cost_ms, foreground），可通过 `/api/history` 查询
- **需要 memory-agent 做的**：提供模板存储 API（存/检索/参数化执行），TVPilot 或管家调用
- **注意**：路线图已变更——模板的存储/检索/执行/沙箱统一由管家技能系统承担，TVPilot 不自己做模板引擎。所以这部分实际是管家侧的事，memory-agent 只做底层存储。

## 5. 给 mytv（电视端 App）

### 5.1 换台方式对齐

mytv 已从播放器改为 IPTV 外挂壳，换台靠 ADB 输入数字键（`zapFromBackground(频道号)`）。

- **TVPilot 当前做法**：ADB `input keyevent` 发数字键
- **mytv 已有 API**：`/api/zap?channel=XXX`（HttpServer.kt 里）
- **TVPilot 需要做的**：评估是否改用 mytv 的 `/api/zap` 直接调用（比 ADB 发数字键更可靠），还是继续用 ADB 数字键（已验证可用）
- **结论**：当前 ADB 数字键方案已跑通，暂不改。等联调时验证 `/api/zap` 是否更可靠再决定。
