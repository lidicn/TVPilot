## 详细修复说明

### RA-02: POST 双读 body

**问题**：`do_POST` 第623行先 `_read_body()`，第644行代理分支又 `rfile.read(length)` → rfile已读完，线程永久挂起。

**修复**：
- `_read_body` 中保存 `self._raw_body = raw`
- 代理分支用 `getattr(self, '_raw_body', None)` 替代二次读取

**文件**：`tvpilot_server.py:545, 643-645`

---

### RA-01: `_http_json` 丢失

**问题**：重构时函数被删除，但 `heal_loop:461` 仍调用 → 每60秒 NameError 被吞，自愈链路空转。

**修复**：从 backup 移植函数（约5行），加在 `rearm_tv` 前。

**文件**：`tvpilot_server.py:438-445`

---

### FL-02+FL-05: FaceID 收藏同步

**问题**：
- URL `http://{ADB_HOST}:10482` → ADB_HOST含`:5555` → 非法地址 `:5555:10482`
- add/remove 都用 POST + 相同载荷 `{'channel': ch}` → 服务端无法区分

**修复**：
- 定义 `_TV_IP = ADB_HOST.split(':')[0]`，`MYTV_HTTP_BASE = f'http://{_TV_IP}:10482'`
- add 用 POST，remove 用 DELETE（query参数传channel）

**文件**：`tvpilot/faceid.py:10-15, 48, 57-75`

---

### FL-01: 语音换台匹配

**问题**：`alias.lower() in text_lower` 子串匹配 → "cctv15"匹配到"cctv1"。

**修复**：
- 别名按长度降序排序（最长匹配优先）
- 数字结尾的别名检查后一个字符，若也是数字则跳过

**验证**：
```
"我要看cctv1" -> 中央一台 ✅
"我要看cctv15" -> None ✅（不再错误匹配）
"cctv5" -> 中央五台 ✅
```

**文件**：`tvpilot/voice.py:32-58`

---

### RA-03: 换台前台超时

**问题**：`ZAP_FOREGROUND_TIMEOUT` 默认30s（基线和整改文档均钉8s），无RPT记载变更。

**修复**：默认值 `'30'` → `'8'`（仍可通过环境变量 `TVPILOT_ZAP_FG_TIMEOUT` 覆盖）

**文件**：`tvpilot/tools.py:29`

---

### FL-14: 裸 int() 参数校验

**问题**：`minutes = int(q.get('minutes', ['60'])[0])` → 非数字返回500而非400。

**修复**：try/except 捕获 ValueError/TypeError，返回 `{ok:false, error:'invalid_parameter'}` + 400。

**文件**：`tvpilot/routes/monitor.py:12-17, 23-28`

---

### RA-05: 截图 fmt 默认值

**问题**：基线默认 `'json'`，重构后改成 `'png'`，无RPT记载。

**修复**：改回 `'json'`。

**文件**：`tvpilot/routes/media.py:134`

---

### FL-04: MQTT 去重 key

**问题**：key只含 `(topic, action, channel, key)`，坐标/文本/包名不入key → 10s内不同tap/input被误杀。

**修复**：key加入 `x, y, text, package, keyword`。

**文件**：`tvpilot/mqtt.py:144-147`
