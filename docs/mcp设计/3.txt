# TVPilot-MCP-Server 设计与实现

## 一、核心设计思路

严格遵循**零新依赖、不修改现有文件、工具数≤10、响应去包装、截图返回 URL**五大约束，基于标准库自实现 MCP 2025-03-26（JSON-RPC 2.0）协议，同时支持 `stdio` 和 `HTTP/SSE` 两种传输模式。所有能力完全复用现有 `tvpilot` 内部模块，仅做协议适配层封装。

### 工具收敛方案（共 10 个，刚好满足≤10 约束）

完全覆盖 §0 列出的所有可调用函数，从 20+ API 收敛为 10 个标准化 MCP 工具：

表格

| MCP 工具名 | 底层实现函数 | 功能说明 |
| --- | --- | --- |
| `tv_foreground` | `tool_foreground` | 查询当前前台应用包名 |
| `tv_system_state` | `tool_system_state` | 获取电视系统状态 |
| `tv_keyevent` | `tool_keyevent` | 发送标准按键事件 |
| `tv_tap` | `tool_tap` | 点击屏幕指定坐标 |
| `tv_input_text` | `tool_input_text` | 输入文本（支持中文） |
| `tv_go_home` | `tool_combo_go_home` | 返回桌面（带前台验证） |
| `tv_launch_app` | `tool_launch_app` | 启动指定应用 |
| `tv_zap` | `tool_zap` | 切换电视频道 |
| `tv_screenshot` | `tool_screenshot` | 截图（返回 URL，默认 240p） |
| `tv_blueprint_run` | `BlueprintRunner` | 运行预定义蓝图流程 |

---

## 二、完整实现代码：`tvpilot/mcp.py`

```
TVPilot MCP Server 适配层
协议版本：MCP 2025-03-26 (JSON-RPC 2.0)
传输支持：stdio / HTTP+SSE
约束：零第三方依赖、不修改现有模块、响应去包装、截图返回URL

import sys

# ---------------------------------------------------------------------------
# 内部处理函数
# ---------------------------------------------------------------------------
def _handle_blueprint_run(name: str, params: Optional[Dict[str, Any]] = None) -> Dict[str, Any]:
    """蓝图运行适配器：复用现有BlueprintRunner"""
    runner = BlueprintRunner()
    runner.register_builtins()
    result = runner.run(name, params=params)
    return result.to_dict()

def _process_screenshot_url(
    data: Dict[str, Any], request_context: Optional[Dict[str, Any]] = None
) -> Dict[str, Any]:
    """截图结果后处理：路径转URL，移除base64，只保留关键字段"""
    result = {}
    # 保留核心字段
    if "width" in data:
        result["width"] = data["width"]
    if "height" in data:
        result["height"] = data["height"]

    file_path = data.get("path")
    if file_path and os.path.exists(file_path):
        basename = os.path.basename(file_path)
        dest_path = os.path.join(SCREENSHOT_DIR, basename)
        if not os.path.exists(dest_path):
            shutil.copy2(file_path, dest_path)

        if request_context and request_context.get("http_host"):
            scheme = request_context.get("scheme", "http")
            host = request_context["http_host"]
            result["url"] = f"{scheme}://{host}/screenshots/{basename}"
        else:
            result["url"] = f"file://{os.path.abspath(dest_path)}"

    # 强制移除base64字段
    result.pop("base64", None)
    return result

# ---------------------------------------------------------------------------
# JSON-RPC 核心处理
# ---------------------------------------------------------------------------
def _jsonrpc_error(
    request_id: Optional[Any], code: int, message: str, data: Any = None
) -> Dict[str, Any]:
    resp = {
        "jsonrpc": "2.0",
        "id": request_id,
        "error": {"code": code, "message": message},
    }
    if data is not None:
        resp["error"]["data"] = data
    return resp

def _jsonrpc_result(request_id: Optional[Any], result: Any) -> Dict[str, Any]:
    return {"jsonrpc": "2.0", "id": request_id, "result": result}

def _handle_initialize(params: Dict[str, Any]) -> Dict[str, Any]:
    """MCP 初始化握手"""
    return {
        "protocolVersion": MCP_PROTOCOL_VERSION,
        "capabilities": {"tools": {}},
        "serverInfo": {"name": SERVER_NAME, "version": SERVER_VERSION},
    }

def _handle_tools_list(params: Dict[str, Any]) -> List[Dict[str, Any]]:
    """返回工具列表"""
    return [
        {
            "name": t["name"],
            "description": t["description"],
            "inputSchema": t["inputSchema"],
        }
        for t in TOOL_DEFINITIONS
    ]

def _handle_tools_call(
    params: Dict[str, Any], request_context: Optional[Dict[str, Any]] = None
) -> Any:
    """调用工具，直接返回数据，去掉ok/cost_ms外层包装"""
    tool_name = params.get("name")
    if not tool_name or tool_name not in TOOLS_MAP:
        raise ValueError(f"未知工具: {tool_name}")

    tool_def = TOOLS_MAP[tool_name]
    arguments = params.get("arguments", {})

    # 解析处理函数
    handler = tool_def["handler"]
    if isinstance(handler, str):
        handler = globals()[handler]

    # 调用底层工具（沿用三元组返回契约）
    raw = handler(**arguments)
    if isinstance(raw, (tuple, list)) and len(raw) == 3:
        data, err_code, err_msg = raw
    else:
        data, err_code, err_msg = raw, None, None

    if err_code is not None or err_msg is not None:
        raise RuntimeError(err_msg or f"工具错误: {err_code}")

    # 后处理（仅截图需要）
    post_process = tool_def.get("post_process")
    if post_process == "screenshot_to_url":
        data = _process_screenshot_url(data, request_context)

    return data

def handle_jsonrpc_request(
    request: Dict[str, Any], request_context: Optional[Dict[str, Any]] = None
) -> Dict[str, Any]:
    """统一入口：处理单个JSON-RPC请求"""
    if not isinstance(request, dict) or request.get("jsonrpc") != "2.0":
        return _jsonrpc_error(None, -32600, "Invalid Request")

    request_id = request.get("id")
    method = request.get("method")
    params = request.get("params", {})

    if not isinstance(params, dict):
        return _jsonrpc_error(request_id, -32602, "Params must be object")

    try:
        if method == "initialize":
            return _jsonrpc_result(request_id, _handle_initialize(params))
        elif method == "tools/list":
            return _jsonrpc_result(request_id, _handle_tools_list(params))
        elif method == "tools/call":
            return _jsonrpc_result(request_id, _handle_tools_call(params, request_context))
        else:
            return _jsonrpc_error(request_id, -32601, f"Method not found: {method}")
    except ValueError as e:
        return _jsonrpc_error(request_id, -32602, str(e))
    except RuntimeError as e:
        return _jsonrpc_error(request_id, -32001, str(e))
    except Exception as e:
        return _jsonrpc_error(request_id, -32603, f"Internal error: {str(e)}")

# ---------------------------------------------------------------------------
# 传输层1：stdio 模式
# ---------------------------------------------------------------------------
def run_stdio_server() -> None:
    """标准输入输出模式，每行一个JSON-RPC消息"""
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue

        try:
            req = json.loads(line)
        except json.JSONDecodeError:
            resp = _jsonrpc_error(None, -32700, "Parse error")
            sys.stdout.write(json.dumps(resp) + "\n")
            sys.stdout.flush()
            continue

        resp = handle_jsonrpc_request(req)
        sys.stdout.write(json.dumps(resp) + "\n")
        sys.stdout.flush()

# ---------------------------------------------------------------------------
# 传输层2：HTTP + SSE 模式
# ---------------------------------------------------------------------------
class _MCPHTTPHandler(BaseHTTPRequestHandler):
    def do_GET(self) -> None:
        path = urlparse(self.path).path
        if path == "/mcp":
            self._handle_sse()
        elif path.startswith("/screenshots/"):
            self._handle_screenshot_file(path[len("/screenshots/"):])
        else:
            self.send_error(404, "Not Found")

    def do_POST(self) -> None:
        path = urlparse(self.path).path
        if path == "/mcp":
            self._handle_mcp_post()
        else:
            self.send_error(404, "Not Found")

    def _handle_sse(self) -> None:
        self.send_response(200)
        self.send_header("Content-Type", "text/event-stream")
        self.send_header("Cache-Control", "no-cache")
        self.send_header("Connection", "keep-alive")
        self.end_headers()

        self._send_sse("ready", {"message": "TVPilot MCP Server ready"})
        try:
            while True:
                time.sleep(30)
                self._send_sse("ping", {})
        except BrokenPipeError:
            pass

    def _send_sse(self, event: str, data: Any) -> None:
        self.wfile.write(f"event: {event}\n".encode())
        self.wfile.write(f"data: {json.dumps(data)}\n\n".encode())
        self.wfile.flush()

    def _handle_mcp_post(self) -> None:
        content_len = int(self.headers.get("Content-Length", 0))
        body = self.rfile.read(content_len).decode("utf-8")

        try:
            req = json.loads(body)
        except json.JSONDecodeError:
            self._send_json(400, _jsonrpc_error(None, -32700, "Parse error"))
            return

        ctx = {
            "http_host": self.headers.get("Host", f"localhost:{DEFAULT_HTTP_PORT}"),
            "scheme": "http",
        }
        resp = handle_jsonrpc_request(req, ctx)
        status = 200 if "result" in resp else 400
        self._send_json(status, resp)

    def _handle_screenshot_file(self, filename: str) -> None:
        filename = unquote(filename)
        if ".." in filename or "/" in filename or "\\" in filename:
            self.send_error(400, "Invalid filename")
            return

        file_path = os.path.join(SCREENSHOT_DIR, filename)
        if not os.path.isfile(file_path):
            self.send_error(404, "Screenshot not found")
            return

        ext = os.path.splitext(filename)[1].lower()
        ctype = "image/png" if ext == ".png" else "image/jpeg" if ext in (".jpg", ".jpeg") else "application/octet-stream"

        self.send_response(200)
        self.send_header("Content-Type", ctype)
        self.send_header("Content-Length", os.path.getsize(file_path))
        self.end_headers()
        with open(file_path, "rb") as f:
            self.wfile.write(f.read())

    def _send_json(self, status: int, data: Dict[str, Any]) -> None:
        body = json.dumps(data).encode("utf-8")
        self.send_response(status)
        self.send_header("Content-Type", "application/json")
        self.send_header("Content-Length", len(body))
        self.end_headers()
        self.wfile.write(body)

    def log_message(self, format, *args) -> None:
        pass  # 禁用默认日志，避免污染stdio输出

def run_http_server(port: int = DEFAULT_HTTP_PORT, host: str = "0.0.0.0") -> None:
    server = ThreadingHTTPServer((host, port), _MCPHTTPHandler)
    print(f"TVPilot MCP HTTP server running on http://{host}:{port}/mcp", file=sys.stderr)
    try:
        server.serve_forever()
    except KeyboardInterrupt:
        server.shutdown()

# ---------------------------------------------------------------------------
# 主入口
# ---------------------------------------------------------------------------
def main() -> None:
    if len(sys.argv) > 1 and sys.argv[1] == "--stdio":
        run_stdio_server()
    elif len(sys.argv) > 1 and sys.argv[1] == "--http":
        port = int(sys.argv[2]) if len(sys.argv) > 2 else DEFAULT_HTTP_PORT
        run_http_server(port=port)
    else:
        run_stdio_server()

if __name__ == "__main__":
    main()
```

## 五、关键设计决策说明（§7）

### 1. 数据结构与索引选择

- **工具双层结构**：用列表存定义保证顺序，用字典做名称映射实现 O (1) 查找，兼顾可读性和调用效率。
- **统一 JSON-RPC 构造函数**：所有响应通过统一函数生成，严格遵循 2.0 规范，避免格式不一致。
- **截图托管方案**：统一存放到系统临时目录，文件名直接映射 URL 路径，无需额外索引表；内置路径遍历防护，保证安全。

### 2. 失败 / 降级语义

- **协议级错误（fail-closed）**：解析失败、方法不存在、参数无效直接返回标准 JSON-RPC 错误码，不降级。
- **工具级错误（透传语义）**：完全复用现有工具的失败逻辑，MCP 层不做额外降级；工具内部的降级（如按键 ADB→6095 端口）由原有实现自行处理。
- **SSE 连接断开（fail-open）**：SSE 仅做状态推送，断开不影响核心 POST 调用，工具调用仍可正常进行。
- **截图后处理降级**：若 HTTP 上下文缺失，自动降级为`file://`本地 URL，保证 stdio 模式下仍可用。

### 3. 与现有实现的兼容边界

- **完全不侵入现有模块**：所有能力通过 import 调用，不修改任何原有代码，严格遵循`(data, err_code, err_msg)`三元组返回契约。
- **参数透传原则**：工具参数直接透传到底层函数，不做重复校验，由原有工具负责合法性检查，避免逻辑冗余。
- **截图返回兼容**：自动读取`path`字段生成 URL，强制移除`base64`字段，不依赖现有截图工具的具体返回结构。
- **蓝图调用兼容**：直接实例化`BlueprintRunner`并调用标准方法，完整保留蓝图系统的所有能力与语义。

### 4. 待明确需求点（未猜测，需确认）

1. SSE 是否需要推送工具调用的异步进度 / 事件？当前仅实现心跳与就绪事件，工具调用通过同步 POST 返回。
2. stdio 模式下截图 URL 是否要求 HTTP 格式？当前返回`file://`本地 URL，若需 HTTP 则要求必须同时启动 HTTP 服务。
3. 蓝图运行结果是否需要精简字段？当前完整返回`BlueprintResult`结构，包含`ok`、`steps`等字段，是否属于 “ok 包装” 需要去除。
4. HTTP 服务器默认端口与绑定地址是否需要通过环境变量配置？当前固定为`0.0.0.0:8765`。
