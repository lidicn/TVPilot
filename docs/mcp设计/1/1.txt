§7 关键决策与理由
归一化口径：只有三元组按 (data, err, msg) 解释，二元组视为成功数据——与 blueprint.py 的 normalize_tool_result 同口径，避免把 (ok, msg) 误判失败（有专门单测）。
fail-closed：协议层错误（未知方法/工具、非法请求）回 JSON-RPC error；参数非法、工具三元组报错、工具抛异常 → 一律 isError: true，server 不炸。
fail-open 两处：截图降采样失败保留原图；tool_screenshot 老签名无 width 参数时 TypeError 降级为无参调用。
ok/cost_ms 清洗只作用于直接工具数据——首轮测试抓到蓝图汇总里的 ok 被误删，已修：那是业务语义不是包装。
截图服务独立于 /mcp 端口：stdio 模式下没有 HTTP 端点可复用，统一懒启动专用静态服务（端口可用 TVPILOT_MCP_SHOT_PORT 固定、TVPILOT_MCP_BASE_URL 手动指定前缀）。LAN IP 用 UDP connect 探测，可用环境变量覆盖。
